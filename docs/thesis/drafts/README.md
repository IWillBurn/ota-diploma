# Черновики главы 4

Заготовки новых пп. 4.3.9–4.3.12 и окончания главы 4 с метками `<<…>>` для чисел, которые ещё считаются. Порядок: вписать значения в `fill_values.json`, `python fill.py` (должно остаться 0 меток), `python ch4_patch_b.py`. После применения каталог можно удалить. В сборку ВКР (`tools/build_docx.js`) не входит.
